# 꽁알꽁알 · 디자인 진단 & 개편 계획

살아있는 디자인 크리틱. 구현은 이 문서에 대고 계속 검증한다.

## 지금 뭐가 아쉬운가

**랜딩(비로그인)** — 가장 큰 문제. 첫인상이 작은 "로그인하세요" 박스 하나(App.jsx). 제품이 뭘 해주는지, 왜 가입해야 하는지 0. 히어로·가치제안·작동방식·미리보기 전부 부재.

**회원가입** — `required` 말고 검증이 없다. 이메일 형식/비번 강도/비번 확인/서버 400 필드 매핑 전무. 계정 생성과 초기설정(키워드·채널·사이트)이 뒤섞일 여지 → 계정정보만 받도록 분리 필요. 온보딩이라는 개념 자체가 없음.

**모달** — `ModalShell`은 접근성(포커스 트랩·Esc)은 좋으나, register/interest/auth 모달이 `flex column`이 아니라 내용량에 따라 크기가 요동치고 내부 스크롤이 불안정. 닫기 `×`는 텍스트 글리프(font-size:24px)라 수직 정렬이 미세하게 어긋남. `?` 도움말 버튼과 hit-area·정렬 규칙이 제각각.

**모션** — 모달 enter는 있으나 exit가 없어 뚝 끊김. 뷰/탭 전환, 리스트 진입, press 피드백이 없어 정적이고 밋밋함.

**기능 공백(계약)** — 사이트별 즉시 "동기화" 버튼 없음. 사이트 등록이 임의 URL 방식(카탈로그 아님). 채널 연동 확인 메시지 피드백 없음.

## 개편 방향

- **디자인 시스템**: App.css의 `--c-*`/`--radius-*`/`--shadow-*` 토큰을 확장(모션 이징·듀레이션, 레이어드 섀도우, hero 그라디언트). 브랜드 블루 `#1677f2` + AI 바이올렛 `#6a5cff` 유지, 친근한 "-요" 보이스 유지.
- **모달 v2**: `ModalShell`을 합성형(title/subtitle/onClose/size/footer/accessory)으로 개편 → 모든 모달이 `flex column` + `max-height` + 본문만 스크롤 + 고정 헤더/푸터. 닫기·도움말 버튼은 `.modalIconBtn`/`.helpButton` 공통 규칙(정사각 hit-area, flex 정중앙, lucide 아이콘). enter/exit 애니메이션 내장(`prefers-reduced-motion` 존중).
- **랜딩**: 전용 풀페이지(대시보드 헤더 대신 마케팅 내비). 히어로(헤드라인+서브+CTA 2종) → 목업 대시보드 프리뷰 → "이렇게 동작해요" 3스텝 → 기능 하이라이트 3종(AI 선별·멀티채널 알림·자동 수집) → 마무리 CTA. 반응형.
- **온보딩 위저드**: 로그인 & `onboarded===false`일 때 풀페이지. ①관심 키워드 ②알림 채널(이메일 자동+슬랙 선택, `?` 도움말) ③사이트 선택(카탈로그). 진행바·back/next·건너뛰기. 완료 시 `onboarding/complete` → 대시보드.
- **모션 레이어**: 뷰 전환 fade, 리스트 stagger, hover/press(≤200ms) 마이크로 인터랙션 전역 적용.
- **계약 기능**: 사이드바 사이트별 동기화 버튼(스피너→"N건 새로 추천"), 첫 구독 직후 자동 sync, 카탈로그 기반 등록 모달, 채널 연동 확인 메시지 반영.
